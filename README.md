# Enterprise Network Infrastructure Lab

## Overview
This project simulates a small enterprise network built using Cisco Packet Tracer. The topology demonstrates centralized network management, dynamic IP allocation, and core network services.

## Topology
Star topology with a central switch connecting:

- Router
- DHCP Server
- DNS Server
- FTP Server
- PCs
- Laptops
- Network Printers

## Configurations Implemented

- DHCP configuration for dynamic IP addressing
- DNS server setup for hostname resolution
- FTP server deployment
- Router interface configuration
- End-device connectivity testing

## Skills Demonstrated

- Network topology design
- Router & switch configuration
- DHCP & DNS services
- Network troubleshooting
- Cisco Packet Tracer lab simulation
